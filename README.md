# Shreyanshu Kumar | Portfolio

My personal portfolio showcasing my projects, technical skills, education, and achievements as a Computer Science & Engineering student at Graphic Era Hill University and an aspiring full-stack developer.

Built with HTML, CSS, and vanilla JavaScript, with a warm latte, cream, and burgundy theme.

## Features

- Responsive layout with mobile navigation.
- Animated particle background, typing effect, scroll reveals, and counters.
- Featured projects with source code and demo links where available.
- Dedicated sections for skills, background, achievements, and experience.
- Downloadable PDF resume.
- Contact form with client-side validation and Formspree integration.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Shreyanshu-kr/Portfolio.git
cd Portfolio
```

Open `index.html` in your browser. No build step or package installation is required.

Alternatively, if Python is installed, serve the folder locally:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

An internet connection is needed to load Google Fonts and Phosphor Icons and to submit the contact form.

## Customization

- Edit `index.html` to update the biography, project cards, social links, and experience.
- Adjust the theme and layout in `style.css`. Canvas particle colors are defined separately in `script.js`.
- Replace the resume PDF and update its links in `index.html` if the filename changes.
- To reuse the contact form for another portfolio, replace its Formspree `action` URL in `index.html` with your own endpoint.
